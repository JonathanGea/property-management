# Rentora — manajemen properti sewa

Rentora memakai istilah **properti sewa** untuk tempat yang dikelola pemilik dan **unit sewa** untuk objek yang disewakan. Pemilik mencatat penyewa aktif, melihat daftar serta riwayat seluruh penghuni lintas properti, dan mencatat pembayaran sewa bulanan.
